## 📖 About

Ecoleta is a full-stack application that allows users to register and discover recycling collection points.

The project was inspired by the original **Rocketseat Next Level Week (NLW)** Ecoleta application, but was rebuilt using modern development practices, focusing on software architecture, maintainability and scalability.

---

## ✨ Features

- ✅ User authentication
- ✅ JWT authorization
- ✅ Register collection points
- ✅ Upload images
- ✅ Local file storage
- ✅ AWS S3 support (planned)
- ✅ Interactive map
- ✅ Search collection points
- ✅ Filter by collection items
- ✅ Form validation
- ✅ Error handling
- ✅ RESTful API
